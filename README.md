# SharkBot

A Tampermonkey userscript that adds a helper panel to [Space Alpha](https://spacealpha.net/). It saves your planets' data as you browse the game and uses it to calculate credit generation and upgrade costs.

**Version 4.0.0**

## Install

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Open **https://raw.githubusercontent.com/SharkyMakesScripts/SharkBot/main/SharkBot.user.js**. Tampermonkey shows its install page: click **Install**.
3. Reload any spacealpha.net page. The panel appears at the top right.

**Opera / Opera GX:** install Tampermonkey from Opera's own add-ons store (https://addons.opera.com/en/extensions/details/tampermonkey-beta/), not the Chrome Web Store, which Opera blocks. Then open **opera://extensions**, turn on **Developer mode** (top right), click Tampermonkey's **Details** and turn on **Allow user scripts**. If SharkBot still doesn't appear, turn Developer mode off and on again and restart Opera. The Welcome tab says the same.

**Install only from that link, and update with SharkBot's Update button.** Don't paste SharkBot into a new script (Create a new script): that installs a second copy, and two copies running at once make SharkBot glitchy. If a red bar says two copies are installed, delete the older one in the Tampermonkey dashboard. To reinstall, open the link again; your registration and data are kept.

The panel can be dragged by its header and collapsed with **−**. Drag its bottom-right corner to resize it (double-click the corner to reset), or click **⤢** to expand it to fill the screen and again to go back. Size, expanded state and UI size are remembered. Your data is stored in your browser through Tampermonkey; nothing is sent anywhere.

## Registration

SharkBot unlocks once Sharky accepts you. Until then the panel shows only a **Welcome** tab (what SharkBot does, how to start, and the **Register** box). Once you're accepted, Welcome disappears, the panel opens on General → Debug and the tour starts for first-time users; if your copy is locked again, Welcome comes back.

1. Open the game so the top bar shows your username; SharkBot reads it from there.
2. Click **Register**. This sends your username, your copy's install code (a random code made by each SharkBot copy) and the SharkBot version to Sharky. Sharing your data is a separate choice (see **Sharing** below).
3. Wait for Sharky to accept. SharkBot checks every 15 minutes (or click **Check now**), and once you're accepted also when you open a game page or come back to the game tab after 30 minutes, and when you click **Check for update**.

Each browser registers separately. Reinstalling in the **same browser** (for example pasting a new version into a new script) keeps your registration: SharkBot keeps a backup of its install code in the game site's browser storage (since v3.14.3). If the game shows a different account than the one you registered, SharkBot locks again until that account registers. If you're denied, you can register again 24 hours later (unregistering doesn't shorten the wait). If Sharky's server can't be reached, your last status is kept. **Unregister** in ⚙ Settings → Sharing & registration (click twice) gives up access: SharkBot locks again, and you can register again any time.

## Password

**SharkBot password** (since v3.30.0, required): the first time SharkBot runs it asks you to create a password (at least 8 characters, typed twice). Everything SharkBot saves in your browser is then encrypted with it (AES-256), including your registration. Your password never leaves your browser: it isn't sent to Sharky, the game or anyone, and nobody can see or recover it. SharkBot asks for it once each time you start your browser; reloading the game doesn't ask again.

- **Remember me** (since v3.32.0, off by default): tick it on the lock screen to stay unlocked on that computer, even after restarting the browser, until you click 🔒 Lock now or change your password. Anyone using that browser profile can then open SharkBot. The lock screen can be dragged by its title and resized from its corner.
- **⚙ Settings → Password:** **Change password** (type the current one and the new one twice) or **🔒 Lock now** (asks again on the next page load).
- **Forgot your password?** Click **Forgot password?** on the lock screen. Because the data is encrypted, SharkBot deletes its saved data on that browser; you create a new password and register again. If you saved a file with **Download my data**, import it afterwards (⚙ Settings → Backup & restore). Keep a recent backup.
- **Reinstalling:** if SharkBot is reinstalled in the same browser, it offers to unlock your earlier registration with the same password, or start fresh.

## Getting started

The first time the panel opens, a short interactive tour (15 steps, rewritten in v3.22.0) shows auto-scan working live, Manual Scan, the panel and its tabs, the pages that need a click from you, the calculators and how they explain themselves, Net Worth, your sharing choices, updates and Settings, and ends with a checklist of pages still to visit for the open planet. You can skip it, and replay it anytime from **⚙ Settings → Restart tutorial**. Players who saw the older tour get a one-time **Take the tour** / **No thanks** offer.

1. Just play. SharkBot **scans automatically** each time you open a game page: it reads the planet name from the game (the planet box at the top left, or the Nation page's "Planet:" heading) and saves everything to that planet's slot. Each new planet you scan is added automatically and named after the game, up to 10 planets. The Debug tab shows which planet was detected.
2. Visit these pages on each planet (they're saved as you go, and again whenever you come back):
   - **Nation:** population, growth, army, sickness, pollution, forest and planet defense
   - **Train Units:** unit counts
   - **Facilities:** use the **new view**. One scan reads every section at once: each facility's level, what it gives, the engineers it needs, its maintenance per tick and its slider, every Area's level and how full it is, and the **Planet surplus**. If a section is collapsed, click **Expand** first (it's all expanded the first time you open the page). **Hover each Area** to save its free space ("Room for … Units"). Facilities saved from the old view are kept until a new-view scan replaces them
   - **Research:** shared by all planets. Each scan adds or updates the research it sees and keeps the rest, so if the Research page splits research into groups, scan each group once. Your **brains**, **diamonds** and **SSB** counts are saved from this page too
   - **Bank:** scan both tabs. Your own bank tab saves **your bank balance**; the **TRAPs** tab saves your investments, the **NERDs** tab saves your NERDs (switching to it doesn't change the page address, so click **Manual Scan** there (on NERDs too)); the **Central bank** tab saves the **galaxy fee** and the Central bank's stats. They're stored separately
   - **Market:** current prices
   - **Cards → All Hero cards:** your card collection (shared by all planets)
3. Every page also saves the planet's inventory (the Planet Inventory box at the top) Colony status (productivity, happiness, sickness) is saved the moment it appears: hover the colony face in the top bar on each planet, and open the **Colony Status** window (click the face) once so the **work mode** is saved too.

Click **Manual Scan** to rescan the current page anytime. Auto-scan can be turned off in **⚙ Settings**. The Save buttons in each tab do the same as Manual Scan. If the other planet is open in the game, they refuse, so data never lands in the wrong slot.

## Tabs

The main tabs are General, Data, Calculators and Statements, plus **Welcome** while your copy isn't registered yet. **Settings** opens from **⚙** in the header (since v3.28.0): a window over the panel you can move, closed with ✕ or Esc.

**Your own tab layout** (since v3.28.0): **drag** any main tab or subtab along its bar to move it; **drag it off the panel** to open it in its own window on the game page (move it by its title, resize from the corner; it keeps updating, stays open when the panel is collapsed, and ✕ puts it back). Dragging a main tab off (for example Statements) opens all its subtabs in one window with their own buttons. **Hover** a tab for **👁** to hide it; **Show hidden (N)** at the top of the panel lists hidden tabs to bring back. Your layout is kept in this browser (Reset all saved data keeps it); **Reset tab layout** in ⚙ Settings → Window & UI size puts everything back. Admin's Dashboard can't be hidden or popped out.

Each main tab remembers which subtab you last opened. **SharkBot never changes your tab by itself** (since v3.22.3): only the tour, which you start, moves between tabs. Messages such as a failed save show for a few seconds in a note at the top of the panel instead. **Expand all / Collapse all** (top right of every subtab with parts that open and close: planet slots in Units, Research and Facilities, investments in Bank and TRAPs, the Cards lists) opens or closes everything there at once. **Every table with column titles can be sorted:** click a title to sort by it, click again to reverse (▲ / ▼ shows which). Numbers and dates sort largest/newest first on the first click, words A→Z; empty cells stay at the end, and totals stay at the bottom. Each table remembers its sort (Reset all saved data keeps it). **All text in the panel can be selected and copied** (since v3.21.1), except the header bar, which drags the panel.

## Notes

- Turns are one empire-wide pool: the Tick Generator and Turn Storage are each on one planet (SharkBot finds whichever planet has them), and every calculator uses those turns for all planets.

- **Numbers in your browser's language** (since v3.26.1): in Italian, German, Spanish and other languages that write 1.234.567,5, the game's full numbers (like 30.430.000.000) are read correctly. Numbers you type into SharkBot are read the usual way ("85.505" is 85.505; since v3.27.3). Before v3.26.1 the game's numbers were read about a sextillion times too small: if your Net Worth or bank looked tiny, rescan Bank, Market and each planet's pages.
- Market prices are treated as the price of a single unit when converting resources to credits.
- Cost calculators (Turn Gen, Area Size) count your **capital**: credits on every planet and in the bank, plus stored resources you could sell at the market sell price. Resources an upgrade consumes are set aside first, and anything missing is priced at the market buy price.
- Best Spend and the All capital blocks assume an area's size is how many workers it holds, and that the new room is filled by training workers. Training costs turns (Training's Soldiers & workers per turn, with your best card), valued at the Value Optimizer average turn; options are ranked by credits/day per (credits + training turn value), and payback includes it. Industrial Area → industrial workers, Commercial Area → commercial workers, an area named like "Mines" → mine workers. An extra turn is worth the Credit Gen credits per turn plus the Resource Gen credits per turn. Materials you own are valued at the sell price, missing ones at the buy price.
- Brains, diamonds and SSB each count only when their tick box is on, at the value you set in Best Spend (or the market sell price if the market lists them).
- Research effects marked "—" haven't been documented yet.
- Saved data is only as fresh as your last scan; each tab shows when its data was saved.
- **Planet order** (since v3.19.0): planets are listed in the game's order (main planet first) everywhere, whatever order you scan them in. SharkBot reads it from the game's planet list: open the **▾** under the planet picture. That list shows every planet except the one you're on, so (since v3.21.2) SharkBot only places a planet once it has appeared in the list opened on another planet, and the first two planets are only told apart by a list opened on a third. Open the list once on two or three different planets and the order is complete; until then Settings → Planets says which planets aren't placed yet or which pair it isn't sure of, and they're in scan order before the list is opened at all. Use ▲ / ▼ in **Settings → Planets** to set your own order; **Use the game's order** goes back. A planet's letter is its place in this order (first = A, since v3.25.2); reordering changes the letters, never the data. "someplanet" (the game's name while a page is still loading) is never added as a planet.
- The helper holds up to 10 planets. With more, scanning an 11th tells you; remove one in **Settings → Planets** to make room.
- Wide tables (Inventory, Nation) scroll sideways when you have many planets.
- **Clear** on a slot erases its data but keeps the planet name. **Settings → Reset all saved data** erases planets, research, market, bank, debts and calculator inputs; your Net Worth history, planet order, registration (so you stay accepted on the same device), color scheme and panel layout are kept.
- If something doesn't save, the Debug tab's Status line says why. Use **⧉ Copy** (General → Debug) to share the scan output when reporting a problem.

## Updating

Click **Check for update** in the panel header. SharkBot also looks for a new version every time you load or refresh a game page (since v3.27.2), and checks in with Sharky's server every 15 minutes and when you come back to the game tab after 30 minutes. When a newer version is out, a bar at the top says so; click **Update** and Tampermonkey opens its own update page: click **Update** there, then **refresh the game page (F5)** to start the new version. A new **x.y.0** version shows an amber **Strongly recommended** bar; only a new **x.0.0** version is required (since v3.30.1 SharkBot no longer reloads by itself: that could run the old and new versions together). Your saved data is kept. Tampermonkey also updates SharkBot by itself from time to time.

If SharkBot can't reach GitHub, Check for update says so (it can't tell whether a newer version is out) and offers **Open update page**, which opens the newest file for Tampermonkey (then refresh the game page).

If the bar says **Update required**, the panel stays locked (except the update bar) until you update.

To update by hand: open the install link above again and click **Update** (or **Reinstall**) in Tampermonkey. Don't paste the new version into a new script; that installs a second copy. Save with **Ctrl+S** and reload the game; the panel header should show the new version. If two copies are installed (for example a new version pasted into a new script), SharkBot shows a red bar across the top of the game page naming both versions and which one to delete (since v3.18.0); delete the older one in the Tampermonkey dashboard and reload. Since v3.27.1 the bar only shows for two real installs: Tampermonkey sometimes runs the same SharkBot twice right after an update, and that's now ignored.

## Version numbers

**public release . private change . small change**. For example, 4.0.0 is the fourth public release, and 4.1.2 would be the fourth public release plus one private change and two small changes. Updating to a new public release (x.0.0) is required; others are recommended.
